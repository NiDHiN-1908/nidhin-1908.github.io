VyaparAI Flagship Project

Lead Developer & Systems Architect
Live Demo

An autonomous multi-agent marketing and conversational sales platform for Indian micro-businesses — automating trend-driven content and WhatsApp commerce across regional languages. VyaparAI is the most complete expression of my systems-architecture approach: agent orchestration, retrieval, and media automation working as one deterministic pipeline.

Live demo status: the deployed dashboard is a work in progress — some backend services and integrations aren't fully live yet, so treat it as a reference for UI and layout rather than a functional preview. The case study below reflects the documented, intended architecture.

View full case study
Business Context

Indian micro-businesses lose real sales to slow response times — a WhatsApp inquiry left unanswered for a few hours converts far worse than an instant reply, and most small sellers can't staff round-the-clock marketing or sales teams.

Overview

VyaparAI is a production-grade multi-agent platform that runs the full marketing-to-sales lifecycle for a small business autonomously — spotting buying intent, generating localized content, and closing the conversation over WhatsApp — without a human operator in the loop.

Problem

Micro-businesses need always-on, multi-lingual marketing and sales conversations but lack the team or budget to staff them manually across channels and languages.

Solution

An 11-agent CrewAI suite, coordinated by a LangGraph state machine, automates the end-to-end pipeline — from lead detection and content generation to deterministic, rule-governed WhatsApp sales workflows.

Architecture

FastAPI backend orchestrating the agent layer, Supabase (PostgreSQL) for persistent state, ChromaDB for vector search, a Next.js 14 frontend for the dashboard, and Docker for containerized deployment.

Workflow

The LangGraph state machine sequences agent hand-offs deterministically: lead signals are captured and embedded, routed to content and sales agents, and resolved into either a generated media asset or a structured WhatsApp conversation step.

Agent Orchestration Diagram
Key Features

RAG-based lead capture over the YouTube Data API v3 with ChromaDB embeddings; deterministic WhatsApp sales flows; Razorpay-integrated payment handling; automated 9:16 vertical video generation with synchronized multi-lingual audio and styled subtitles.

Tech Stack

Python, FastAPI, CrewAI, LangGraph, Ollama (Llama 3.1), Supabase, ChromaDB, Next.js 14, FFmpeg, WhatsApp API, Razorpay, Docker.

Results

Sub-5-second high-intent lead identification, and an automated media pipeline covering five Indian regional languages with synchronized audio and subtitles — engineered to remove manual work from every stage of the funnel.

Engineering Challenges

Keeping 11 agents deterministic rather than reactive under LangGraph's state machine; holding retrieval latency under five seconds as the vector index grows; and synchronizing TTS audio with styled subtitles across five languages inside a single FFmpeg render pipeline.

Current Status & Next Steps

Core architecture and agent logic are built and documented; the public demo deployment is being stabilized — reconnecting backend services and integrations is the immediate next milestone before a fully live walkthrough.

RAGNoviq

Enterprise Retrieval-Augmented Generation Pipeline
Live Demo

A RAG-powered assistant that crawls websites, indexes content into vector embeddings, and answers questions with grounded, cited responses.

View case study
Business Context

Teams need conversational access to their own web content — support docs, product pages, knowledge bases — but generic LLM answers risk hallucinating facts that were never on the source site.

Problem

Enterprises need conversational access to their own web content, with answers grounded in real sources rather than hallucinated.

Solution

An automated crawler and semantic indexer feed a FAISS-backed retrieval layer, returning LLM responses with precise source citations via Groq/Gemini.

Architecture

FastAPI + SQLAlchemy backend, FAISS vector store, sentence-transformers embeddings, React/Vite/TailwindCSS dashboard for multi-website management.

RAG Pipeline
Results

Optimized retrieval by extracting only the top semantic chunks, enabling accurate, session-based conversational answers at low latency.

Engineering Challenges

Balancing chunk size and top-k count to keep retrieved context relevant without overwhelming the LLM's context window; keeping citations accurately mapped back to source URLs after chunking; managing crawl freshness across multiple indexed websites at once.

Future Roadmap

Add incremental re-crawling so indexes stay fresh without full re-ingestion; expand beyond Groq/Gemini to support local model fallback; add prerendering to the deployment so the app is indexable and link-preview-friendly.

ID Forgery Detector

Automated Document Authentication & Fraud Detection

A computer-vision service that analyzes ID document images to detect forgery or tampering, cutting manual review time by 75%.

View case study
Business Context

Manual document verification doesn't scale — onboarding, lending, and KYC teams reviewing IDs by eye are slow and inconsistent, and fraud losses compound the longer a forged document goes undetected.

Problem

Manual ID verification is slow and error-prone, taking roughly 30 minutes of reviewer time per document.

Solution

A FastAPI service applies OpenCV and EasyOCR to extract 14+ verification metrics, classifying forgery risk with 95%+ confidence scoring.

Architecture

PyTorch-backed image analysis pipeline, containerized with Docker, exposed through a FastAPI endpoint for integration into verification workflows.

Results

Reduced manual review time from ~30 minutes to a 2-second automated scan — a 75% reduction — while maintaining high-confidence risk classification.

Engineering Challenges

Getting OCR to hold up across varied lighting, angles, and document formats; tuning the 14+ verification metrics so edge cases don't produce false positives that would block legitimate documents.

Future Roadmap

Expand the verification metric set to cover more document types beyond IDs; add an explainability layer showing reviewers exactly which metrics drove a risk score.

TalentOS AI Building Now

Agentic HR Operating System

An agentic HR platform on a hybrid architecture — a .NET business core paired with a Python AI service coordinated by a LangGraph supervisor. Currently in active development, not yet deployed.

Status: this project is actively being built — no live deployment yet. Included to show current work in progress, not a finished product.

View case study
Business Context

HR platforms typically bolt AI onto an existing system as an afterthought. TalentOS AI is designed the other way around — AI reasoning and business logic as two dedicated, cleanly-separated platforms from day one.

Architecture

ASP.NET Core (.NET 9) owns the business/transactional layer — auth, RBAC, employee records, payroll, audit trails. A dedicated Python/FastAPI service owns AI reasoning, coordinated by a LangGraph supervisor agent routing to specialized sub-agents.

Key Design Decision

AI agents never touch business data directly — every AI action calls the .NET platform through a dedicated integration client. This keeps business logic auditable and AI reasoning replaceable without touching transactional code.

In Progress

Building out the recruitment pipeline: multiple zero-cost candidate intake channels (career portal, referrals, resume upload, CSV/Excel import), vector-based candidate ranking, and an agent-orchestration view in the frontend.

Tech Stack

ASP.NET Core (.NET 9), Python 3.11, FastAPI, LangGraph, React, TypeScript, PostgreSQL (pgvector), Docker.

Current Status & Next Steps

Core service boundaries and the AI supervisor pattern are built; recruitment-pipeline features and deployment are the current focus. No live demo yet — check back or follow the GitHub repo for progress.
